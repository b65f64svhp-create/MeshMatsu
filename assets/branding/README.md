# MeshMatsu branding

Selected artwork created with the built-in image_gen tool:

- `meshmatsu-icon-v2.png`: 1254 × 1254 PNG; five-node mesh M, handheld-screen outline and charcoal rounded tile. Alpha transparency outside the tile. Intended as the source for launcher icons.
- `meshmatsu-logo-dark-v1.png`: 2172 × 724 PNG; horizontal emblem and MeshMatsu wordmark on charcoal. Intended for the home screen and documentation.

Palette direction matches the app: mint green #67EA94 on charcoal #101513. Generated raster colors may vary slightly; use the app constants for future native rendering. Preserve the aspect ratio and clear space. The horizontal wordmark is bundled into the version 26 home header as RGB565 pixel data. Version 27 adds launcher-size PNGs and metadata in ../launcher/; the source icon remains intact.

`meshmatsu-icon-v1.png` is the initial exploration; use v2 for new work. Transparent wordmark explorations were discarded for edge artifacts. The full generation/refinement prompts are recorded in `generation-prompts.md`.
