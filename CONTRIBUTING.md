# Contributing

Please open a GitHub issue before a large change. Describe the problem or feature,
which Tanmatsu/radio firmware you use and how you can test it. Bug reports should
include clear steps and expected/actual behavior. Remove channel keys and QR
links, backup passwords, personal messages and precise locations.

Keep changes focused, preserve existing data formats or document migrations,
and run the host checks relevant to the change. Radio-write features need
protocol/source review and hardware validation. Do not add automatic radio
flashing to an ordinary app update. Keep Packet Runner balance changes separate
from unrelated work.

Submit work you are entitled to contribute under this project's GPLv3 terms,
and preserve third-party notices. New third-party files need source, version and
license information. Please do not include user backups, private import data,
map caches or compiled SDK directories in source commits.

Issues and pull requests are public. A private security-reporting contact has
not been established yet; avoid posting exploitable details or credentials in
public, and first ask the maintainer for a private reporting route without those
details. No response-time or maintenance guarantee is offered for this beta.
