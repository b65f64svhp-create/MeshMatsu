# MeshMatsu v0.62.beta

First app-only public beta for Tanmatsu devices already running the compatible
Tanmatsu Meshtastic2.7.18 radio port. Free download, GPLv3 original code.

Included: channel/DM chats, replies and tapbacks, node actions, telemetry,
range/neighbor tools, SD history/export, offline-map support and first-time
region/name setup. Offline maps and radio firmware are not included.

Download the named app ZIP and SHA256SUMS, and follow INSTALL.md. The named
source ZIP includes locked dependencies and SDK/submodules; GitHub's automatic
source archive is a smaller repository-only snapshot. Retain the corresponding
source asset alongside the app download.

Validated on the owner's Tanmatsu/macOS: packaged installer backup, reinstall,
app CRC/launcher hashes, start and Home/settings/messages intact.111 host suites,
real crypto harness and a clean exported-source build pass locally. Linux,
a separate owner/computer, fresh UNSET-region radio, actual rollback restore
and USB interruption recovery still need independent testing. Windows packaging
is pending. Clean builds are not claimed byte-identical.
